# 🏡 EstateHub — Luxury Real Estate Platform

> **A premium, technology-driven real estate platform for discovering verified properties, connecting with trusted agents, and finding the right property through AI-powered recommendations.**

EstateHub is a modern **Luxury Real Estate Platform** designed to make property discovery simpler, smarter, and more trustworthy.

The platform allows users to browse verified property listings, search and filter properties, save their favorite properties, explore certified real estate agents, and use an **AI-powered Property Matcher & Advisor** to discover properties based on their budget, location, property type, bedrooms, lifestyle preferences, and specific requirements.

---

# ❤️ 6. Favorite Properties

EstateHub provides a dedicated **Favorites** page.

Users can save properties they are interested in by clicking the heart icon on a property card.

The saved properties are stored locally in the browser using:

```text
LocalStorage
```

This allows users to return to their saved properties without having to search for them again.

If no properties have been saved, the platform displays a clean empty-state interface with a button to return to the property catalog.
